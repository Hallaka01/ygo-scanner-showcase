The scanner uses a static, explicitly labeled simulated camera preview and a prefilled draft batch. Its guide and controls are the app's existing UI; the screenshot does not demonstrate live camera recognition.

The banner uses the Millennium palette and framing. No official card illustrations, copied effect text, or private app assets are distributed.

Code extracts preserve the app's core logic. Printing lookup dependencies are omitted; inventory value types are combined into one standalone file.
